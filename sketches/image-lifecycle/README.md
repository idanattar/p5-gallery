# מה קורה לתמונה שלך?

סקיצת p5.js שמראה מה קורה לתמונה בשבע התחנות של מחזור החיים של דימוי: צילום, העלאה והפצה, הגברה, מסגור בכל צד (4א/4ב), בדיקה והכחשה, ארכוב או מחיקה, וזיכרון.

מצלמים או מעלים תמונה מהטלפון (או בוחרים "תמונה לדוגמה"), והיא עוברת בעץ התחנות. בכל תחנה היא משתנה: נדחסת, משוכפלת, נחתכת אחרת בכל צד, נבדקת בידי צ׳אטבוט לא עקבי, מתפרקת, ולבסוף מושלמת בידי AI לזיכרון "מאושר".

התמונה מעובדת בדפדפן בלבד ולא נשלחת לשום מקום.

## הרצה

- בגלריה: הסקיצה נטענת אוטומטית מתוך `sketch.js`.
- לבד: מגישים את התיקייה עם שרת מקומי ופותחים את `index.html`:

```bash
python3 -m http.server 8123
# http://localhost:8123/sketches/image-lifecycle/
```
